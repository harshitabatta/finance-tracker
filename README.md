# Finance Tracker

A private personal finance tracker focused on simple monthly and yearly spending analysis.

## V1 scope

- Track money received and spent
- Date, type, amount, category, and optional note
- Monthly totals and spending ratio
- Top 3 spending categories + Others
- Yearly analysis from January 1 through December 31
- Monthly CSV export
- Responsive PWA for desktop and phone

## Development

```bash
npm install
npm run dev
```

## Environment variables

Create a `.env.local` file with the Supabase project URL and publishable key. Never commit secrets.
